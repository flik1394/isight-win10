iSight 虚拟麦克风驱动（isightmic.sys）使用说明
================================================

这个驱动让 Windows 把一个“真实”的录音设备认出来，名字叫
“iSight Microphone (FireWire)”。微信 / QQ / OBS / 腾讯会议里就能在
麦克风列表里选它。它自己不产生声音——声音由用户态喂音程序（feeder）
通过 IOCTL 灌进去。本版（M1）只是把一段 WAV 循环灌进去，证明整条
内核驱动 + 设备安装链路是通的；把相机真实麦克风接上来的工作（M2）
在另一路做。

--------------------------------------------------
一、一次性前置条件（只需做一次，要重启）
--------------------------------------------------
本驱动是“测试签名”（test-signed）的，Windows 默认不加载，需要打开
测试签名模式：

    以管理员身份打开命令提示符，执行：
        bcdedit /set testsigning on
    然后重启电脑。

重启后桌面右下角通常会显示“测试模式”水印，这是正常的。
（Windows 11 24H2 及以后对内核驱动更严，建议用 Windows 10。）

--------------------------------------------------
二、安装
--------------------------------------------------
右键 install-mic.bat -> “以管理员身份运行”。

脚本会：
  1. 把测试证书 iSightMicTest.cer 装进本机 Root + TrustedPublisher 存储；
  2. 用 isight-micdev.exe 建一个根枚举设备节点，并把 isightmic.sys 装上去；
  3. 提示完成。

装完后到 控制面板 -> 声音 -> 录制 里，应该能看到
“iSight Microphone (FireWire)”。

--------------------------------------------------
三、喂音（让它真的出声）
--------------------------------------------------
驱动装好后，必须有一个喂音程序在跑，否则录音软件拿到的是静音。

M1 验证（用任意一段 WAV）：
    isight-micsvc.exe sample.wav
其中 sample.wav 只要是 48 kHz / 16-bit 的 WAV（单声道或立体声都行，
立体声会自动混成单声道）。程序会循环把这段音频推进驱动，录音软件
录到的就是它。

然后打开微信 / QQ / OBS，在麦克风里选 “iSight Microphone (FireWire)”，
应该就能收到这段音频了。

（真实相机麦克风喂音是 M2，参见仓库路线图。）

--------------------------------------------------
四、卸载 / 回滚
--------------------------------------------------
右键 uninstall-mic.bat -> “以管理员身份运行” 即可移除设备节点并删除
驱动。若想恢复正常的驱动签名强制，再执行：
    bcdedit /set testsigning off
然后重启。

--------------------------------------------------
五、已知限制 / 风险
--------------------------------------------------
- 测试签名驱动：只在“测试模式”下加载；关掉测试模式后设备消失。
- 内核驱动有蓝屏风险。若装上后系统异常，启动时按 F8 / 高级启动进入
  测试模式或禁用驱动强制签名，再用 uninstall-mic.bat 卸载。
- 目前（M1）不是相机真实声音，是 WAV 回放；M2 才接相机麦克风。
- 分辨率/格式固定：48 kHz / 16-bit / 单声道。
